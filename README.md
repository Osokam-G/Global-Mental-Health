# Global Mental Health Dashboard

An exploratory data analysis project examining mental health measures across countries, disorder categories, and years. I inspected the data in Excel, cleaned it in Google Colab, and analyzed and visualized it in Power BI.

## Project Overview

This project explores the mental health measures in a global dataset. The Power BI dashboard summarizes the data and compares measures across countries, disorder categories, and time.

The dashboard displays **231 countries** and includes cards for average depression, anxiety, male, and female measures. It also contains country comparison charts, a disorder category comparison chart, an anxiety trend over time, and a country filter.

## Dashboard Preview



- **Project type:** Exploratory data analysis and visualization
- **Tools:** Microsoft Excel, Google Colab, Power BI

## Project Objectives

The objectives of this project are to:

1. Explore how the dataset’s mental health measures vary across countries.
2. Compare the average values shown for different disorder categories.
3. Examine how the anxiety measure changes over the years in the dataset.
4. Present the analysis in a Power BI dashboard.

## Questions Explored

- How do the recorded mental health measures compare across countries?
- Which disorder categories have higher or lower average values in the dataset?
- How does the anxiety measure change across the years shown?

## Dashboard Results

The Power BI dashboard summarizes mental health measures across **231 countries**. It includes country comparisons, averages by disorder category, average male and female measures, and a trend chart for anxiety over time.

The summary cards display the following values:

| Measure | Value shown |
|---|---:|
| Average depression measure | 3.50 |
| Average anxiety disorder measure | 3.99 |
| Average male measure | 2.80 |
| Average female measure | 4.12 |

In the disorder comparison chart, anxiety disorders have the highest displayed average, followed by depression. The other categories shown—alcohol use disorders, drug use disorders, bipolar disorder, eating disorders, and schizophrenia—have lower displayed averages.

The anxiety trend chart rises from the early 1990s toward around 2010. It then appears broadly level, with a small decrease toward the end of the period shown.


## Interpretation and Limitations

- This analysis describes the dataset used; it does not necessarily represent every country or population.
- Country comparisons may be affected by differences in data collection, reporting, coverage, or measurement.
- A higher value in this dataset does not automatically mean that a country has more people affected or a higher risk.

## Recommendations for Further Analysis

## Recommendations

- **Prioritize further analysis of anxiety and depression.** These categories have the highest average values in the dashboard, so examining their patterns across countries and years may help identify where further investigation is useful.

- **Investigate the rise in the anxiety measure over time.** The trend increases from the early 1990s toward around 2010, then appears to level off. Comparing the underlying yearly values could clarify when the largest changes occurred.

- **Review country-level differences.** Use the country comparison charts to identify locations for closer review, while checking that their data coverage and measurement methods are comparable.
